# ZeldaSwordSkills_Remastered

This repository contains the Minecraft 1.20.1 port of Zelda Sword Skills, originally from 1.8.9 and using Forge 47.x and Java 17. The old source trees and build files have been removed. Old Minecraft saves, metadata variants, APIs, and network protocols are not supported.

The historical mod page is available at <http://www.minecraftforum.net/topic/2239063-164forge-zelda-sword-skills-v047-water-bombs/>. Original code is from <https://github.com/coolAlias/ZeldaSwordSkills>.

## Build and run

Use a Java 17 JDK:

```text
./gradlew clean build
./gradlew runClient
```

Version: `1.0.0`. The release JAR is `build/libs/ZeldaSwordSkills_Remaster_1.20.1_1.0.0.jar`.

## Description

This mod is the fully remake of Zelda Sword Skills from 1.8.9. 
This mod is still in the testing stage. Although this mod attempts to replicate all the contents of the original one, there may still be some incomplete mechanism or functions.

Apart from transferring the original mod content and making it compatible with the ecosystem of 1.20.1, I also made improvements and optimizations to some of the modules of this mod. These include:

 **Completely Recontribute the Sword Skill system** A fully unique way of commanding the sword skills and a fresh combat experience. While retaining the original style of Zelda, it is also adapted to the combat environment of Minecraft.

 **Reshape the temple challenge** The challenge rooms were too narrow for a temple battle, so I enlarge them with more action spaces, more powerful enemies, and more intriguing treasure.

 **Make Navi as your friend** Navi is not just a normal spirit anymore. She can follow you all over your adventure, help in the battle, and even talk to her.

 **Adjustment of equiments** Master sword in old version was too weak. Now it as well as other weapons or tools has a stronger power to fight against the new mobs like wardens, or explore the modern terrains of Minecraft. 

 **More configurable options** Wanna more challenging mode? Or just want to disabled the annoying monsters for the casual players? You can configure them in the mods option.
